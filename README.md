# E-Commerce API Testing Project

## Project Overview

This project focuses on manual API testing using Postman. The main objective is to validate API endpoints, HTTP status codes, response data, and response time.

## Tools Used

* Postman
* Git
* GitHub
* Microsoft Excel

## API Endpoints Tested

| API Name           | Method | Purpose                     |
| ------------------ | ------ | --------------------------- |
| Login API          | POST   | User authentication         |
| Get Profile        | GET    | Retrieve user profile       |
| Get All Products   | GET    | Retrieve all products       |
| Get Single Product | GET    | Retrieve a specific product |

## Testing Types

* Positive Testing
* Negative Testing
* Status Code Validation
* Response Body Validation
* Response Time Validation
* JSON Response Validation

## Test Documentation

API test cases and test results are documented separately in Excel.
